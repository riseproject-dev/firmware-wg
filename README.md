# RISE Firmware WG

## About RISE

[RISE](https://riseproject.dev) is a collaborative, industry-led initiative under the Linux Foundation that accelerates open-source software development for the RISC-V architecture.

## Charter

This working group covers firmware for RISC-V systems, including but not limited to TianoCore UEFI (EDK2), U-Boot, Coreboot, TF-M, and OpenSBI. Our objectives are to:

- Help collaboration across companies to avoid duplication of work
- Accelerate RISC-V firmware development and upstreaming
- Communicate on the readiness of the respective firmware ecosystems
